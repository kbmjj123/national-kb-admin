# 公共组件
---
> 为方便项目中快速使用公共组件，在`components`目录中设计并定义了以下相关的组件，在`components/global`文件夹中的组件则是注册的全局组件，使用时无需再次显示引入来使用！
> 下面将意义列出项目中的公共组件

## 自动导入的全局组件
> 在`components/global`目录中创建并定义了相关的组件，然后凭借统一的入口方法，实现对全局组件的注册，该方法如下：
```typescript
// global/index.ts
import type { App } from 'vue'
/**
 * 对外提供的全局组件注册的动作
*/
export function setupGlobalComponents(app: App) {
	const components = import.meta.glob('./**/*.ts', { eager: true })
	Object.keys(components).forEach(item => {
		if(components[item]){
			app.component(item, components[item])
		}
	})
}
```
:star2: 通过借助于`import.meta.glob(0)`方法，自动导入当前目录下的相关文件对应的`*.ts`入口，然后通过`app.component()`的方式，注册到全局中，然后在`main.ts`入口中引入调用
```typescript
// main.ts
import { setupGlobalComponents } from './components/global'
import { createApp } from 'vue'
import App from './App.vue'
const app = createApp(App)
setupGlobalComponents(app)
```

### 组件清单一览

#### 1. AutoLayout
> 可自我响应式布局的grid布局

#### 2. EmptyGuide
> 空视图组件，并提供对应的点击回调相关交互

#### 3. FixBottomArea
> 固定在所在容器视图底部的区域组件

#### 4. IconfontIcon
> 可直接使用到`iconfont`上的相关图标组件

#### 5. KArea
> 自带标题区域的内容区域组件

#### 6. KEditor
> 项目的图文编辑器

#### 7. KImage
> 包装的自定义图片组件，自带预览功能、自动拼装路径前缀的组件

#### 8. Uploader
> 统一的文件上传组件，支持单个以及多个文件上传的方式
